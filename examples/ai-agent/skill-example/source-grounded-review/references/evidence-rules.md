# Evidence rules

- Source code proves the behavior implemented in that revision, not that production runs the same revision.
- A unit test proves the isolated contract covered by its assertions, not the real network or production environment.
- Command output is evidence only when the command, environment, version, and time are known.
- Official documentation supports public API semantics; local adapters still need source or integration tests.
- A successful transport response does not prove business data, authorization, or answer quality.
- An explanation or analogy may clarify a mechanism, but must not be presented as observed project behavior.
