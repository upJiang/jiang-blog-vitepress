SEO优化隐私政策

生效日期：2026 年 8 月 6 日
最近更新：2026 年 8 月 14 日

本隐私政策适用于 Chrome 扩展“SEO优化”（以下简称“本扩展”）。本扩展的单一用途是：分析用户主动选择的网站搜索增长信号，在本地提供可解释的 SEO、国际 SEO、追踪链路和 SEM 诊断、优化建议及网页元素定位。

本扩展的大部分功能在用户设备上本地运行。本扩展不会把审计报告、浏览记录、CSV、服务器日志、API Key 或 AI 对话自动上传给开发者；只有用户主动配置并调用 AI 服务时，用户选择的服务才会收到本政策第 4.2 节所列数据。该服务可能由开发者或其他第三方运营。本扩展不出售用户数据，也不使用用户数据投放个性化广告、进行跨网站追踪、建立广告画像或向数据经纪商提供数据。

本扩展对从 Chrome API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。

1. 本扩展处理的数据

Chrome 将本地读取、处理或保存也视为“处理用户数据”。为透明说明，本扩展可能处理以下数据。

1.1 当前网页和浏览活动

仅在用户点击扩展、启动扫描、重新验证或使用网页定位时，本扩展处理当前活动标签页的 URL、来源域名及以下网页内容和技术信号：

  • 页面标题、Description、Robots、Canonical、H1-H6、页面语言和可见正文长度；
  • 链接文字和地址、图片 Alt 和尺寸、视频信息、JSON-LD、hreflang、表单数量和可识别的操作入口；
  • HTTP 状态、最终 URL、Content-Type、X-Robots-Tag、允许列出的缓存/压缩/HSTS 响应头、robots.txt、Sitemap 和原始 HTML 与渲染后页面的差异；
  • CSS、JavaScript、图片等资源的地址、类型、加载属性、传输体积可测性、第三方来源和最多 12 个同源 CSS/JS 的允许列出响应头；
  • 本次访问可测的 LCP、CLS、FCP、TTFB 和 Viewport 信号；
  • 用户填写的页面类型、索引目标、目标查询和页面任务。

本扩展不持续记录浏览历史，不在后台跟踪用户访问的所有网站，也不会读取跨域 iframe、closed shadow root、Cookie 的值、网页本地存储、密码、支付卡信息或表单输入值。本扩展为页面技术探测、robots.txt、Sitemap、站点审计和资源响应头采样发出的请求使用匿名模式，不发送 Cookie 或 Authorization。

1.2 站点审计数据

用户主动运行“站点审计”并授予当前网站权限后，本扩展会请求同一来源下的有限数量 URL，处理 URL、状态码、跳转、索引指令、Canonical、标题、描述、正文摘要指纹、内部链接、Sitemap、hreflang、模板分类、HTML 压缩/缓存摘要和 nofollow 数量等 SEO 信号。站点审计遵守 robots.txt，不跨域抓取，也不是持续运行的完整全站爬虫。

1.3 当前网站记录和用户导入数据

扫描当前网页时，本扩展会按当前网站域名在本地自动建立一条网站记录，用于把同一网站的检查结果、追踪测试和用户设置归集在一起；用户不需要输入网站地址或创建项目。用户填写 SEM 目标或导入文件时，本扩展还可能在本地处理：

  • 项目名称、主域名、目标市场、时区、货币、品牌词、排除词、页面任务和核心转化；
  • 查询、页面、展现、点击、CTR 和平均位置等搜索表现数据；
  • 平台、日期、广告系列、广告组、关键词、搜索词、匹配方式、落地页、展示、点击、成本、平台转化和转化价值等广告表现数据；
  • 用户主动映射的有效转化、收入、退款、毛利和转化延迟等业务结果；
  • 用户主动记录的广告变更摘要；
  • 状态码计数、疑似搜索爬虫家族、慢 URL 和参数浪费候选等服务器日志聚合结果。

原始 CSV 和原始服务器日志不会被持久保存。邮箱、电话、姓名、地址等直接身份字段禁止映射。服务器日志中的 IP、完整 Referer 和原始 User-Agent 会在本地聚合时丢弃。本扩展不会自动连接或修改广告账户、预算、出价、否定词或线上网站。

1.4 身份验证信息和 AI 内容

可选 AI 功能由用户自行配置 OpenAI-compatible 服务。本扩展会在本地保存用户填写的 AI 请求地址、模型名称和 API Key，以及用户主动发送的提问和 AI 回复。API Key 属于身份验证信息；AI 提问和对话属于用户生成内容。

本扩展不要求用户创建开发者账户，也不收集姓名、邮箱、电话号码或政府签发的身份信息。

1.5 海外站与主动追踪测试

用户使用“海外站优化”时，本扩展可能在本地处理目标国家或地区、目标语言、主要搜索引擎、核心转化、是否投放 Google Ads 或 Microsoft Ads，以及用户填写的跨域转化域名。本扩展识别页面中的 GA4、GTM、Google Ads、Bing UET、Clarity、百度统计、Consent Mode、点击参数、hreflang 和移动版 alternate 等公开技术信号，并在本地生成海外市场建设判断及搜索访问、本地化内容、海外数据统计、广告追踪和海外转化支持五项能力结论。检查结果归类为已确认正常、已确认问题、条件性优化建议和检测边界；这些分类不会向开发者传输。GTM 容器加载只作为容器证据，不会被当作 GA4 数据请求或平台后台接收证据。

百度统计或 Clarity 的存在只用于说明对应统计工具被发现，不能证明 GA4、Google Ads、Microsoft Ads、平台后台接收或真实业务链路正常。缺少 GA4/GTM、广告标签或多语言页面不会脱离用户的业务前提自动判为网站问题。

Google Search Console、Google Ads、Microsoft Advertising 等平台后台结果不在自动扫描范围内。本扩展不连接 Google/Bing OAuth，不读取或保存相关账户、登录信息、站点列表或后台报告。旧版本中用户手工保存的 Search Console 确认结果仍可在本地兼容读取，0.8.0 不再把该确认流程作为概况任务向导。

普通扫描不会持续监听。只有用户点击“开始测试”后，本扩展才临时观察 dataLayer.push、gtag、uetq.push、sendBeacon、fetch、XHR 和 SPA 路由调用。只保留事件名、平台、相对时间、可安全识别的目标 ID，以及关键字段是否存在。测试最长 10 分钟、内存最多 200 条，停止、超时、页面卸载或权限失效后恢复被包装的方法。

本扩展不保存追踪请求正文、表单值、Cookie、完整 dataLayer/uetq、业务接口响应，或真实 event_id、lead_id、transaction_id 值。每个项目最多保存最近 20 次脱敏测试摘要。用户主动导入 GA4 CSV 时，仅保存映射后的日期、页面路径、来源、媒介、系列、会话、事件名称、关键事件、收入和货币等规范字段；姓名、邮箱、电话和地址等敏感列禁止映射。

2. 数据的用途

上述数据仅用于提供本扩展面向用户的功能：

  • 生成当前页面 SEO 检查结果、页面 SEO 基础分、证据和代码建议；
  • 在用户当前页面上定位检测到的元素；
  • 比较同一网站中的代表页面，发现模板级或站点级问题；
  • 分析用户主动导入的搜索表现、广告表现和业务结果；
  • 检查国际页面配置，并在用户主动开始测试时确认 Google/Bing 标签、请求和主要事件链路；
  • 对比 GA4、广告平台和业务结果的规范化汇总，显示数据缺口和差异；
  • 保存用户配置、诊断结果和复测基线，使浏览器重启后仍可继续使用；
  • 在用户主动发送 AI 问题时，为用户选择的 AI 服务提供诊断上下文。

本扩展不会将这些数据用于信用评估、保险、招聘、个性化广告、广告再营销、与扩展单一用途无关的分析或市场研究。

3. 数据保存位置和期限

  • 当前标签页扫描报告保存在 chrome.storage.session，通常在浏览器会话结束后清除。
  • 网站记录、规范化导入字段、站点审计结果、诊断、扫描基线、广告变更、服务器日志聚合、最近 20 次脱敏追踪测试和海外核对报告保存在扩展的本地 IndexedDB。优化建议由当前证据实时生成，不保存任务状态；旧版本留下的整改记录仅为兼容保留，新版本不再创建。
  • AI 请求地址、模型、API Key 和对话保存在 chrome.storage.local，不会通过 chrome.storage.sync 同步到其他浏览器。
  • 页面正文短片段只在用户主动发送 AI 问题时临时采集，不作为页面报告长期保存。
  • 本地持久数据会保留到用户主动删除、清除扩展数据或卸载扩展为止。

API Key 由 Chrome 扩展本地存储保存。本扩展不会在界面中回显已经保存的完整 Key，也不宣称在 Chrome 提供的本地存储之外增加了额外加密。

4. 数据传输和共享

4.1 页面和站点请求

扫描当前网页及用户主动运行站点审计时，浏览器会向当前网站及其同源 URL、robots.txt、Sitemap 和少量同源 CSS/JS 发出匿名 HTTP/HTTPS 请求。用户点击“检查关联版本”“完整检查网站入口”或配置跨域转化测试时，还会在用户单独授权后请求相应地址；海外概况不会为了关联版本自动弹出权限请求。目标网站的运营者可能按照其自身政策记录这些普通网络请求。本扩展不会把审计结果发送给开发者。

4.2 可选 AI 服务

只有在用户已经填写 AI 请求地址、模型和 API Key，并且在“AI 深度解读”中主动发送问题后，本扩展才向外部 AI 服务传输数据。每次请求可能包含：

  • 当前页面 URL、标题、页面类型、页面 SEO 基础分和分类结果；
  • 当前页面的规则状态、检测证据、根因分组、规范化优化建议与代码方案、性能指标、页面与站点诊断摘要；
  • 用户导入数据形成的 SEO/SEM 汇总和数据缺口；
  • 国际 SEO、标签存在性、Consent、脱敏追踪测试和三方数据核对摘要；
  • 最多 4000 字的当前页面可见正文短片段；
  • 用户本轮提问和当前会话中为连续回答所需的近期对话。

AI 请求通过用户配置的服务地址发送。远程地址必须使用 HTTPS；本机 localhost 或 127.0.0.1 可用于用户自己的本地服务。API Key 仅作为请求的授权凭证发送给该服务。

本扩展不会向 AI 服务发送完整 DOM、Cookie、网页本地存储、表单值、隐藏正文、页面脚本、原始 CSV、原始服务器日志、追踪请求正文、完整 dataLayer/uetq、姓名、邮箱、电话、地址、真实事件/业务记录 ID 或完整站点 URL 列表。AI 服务提供方如何保存和处理收到的数据由该提供方的政策决定，用户应在配置前审查所选择服务的隐私政策。

4.3 其他共享

除上述用户主动触发且为功能所必需的传输外，开发者不会向第三方出售、出租或共享用户数据。本扩展不包含开发者运营的分析 SDK、广告 SDK、跟踪像素或遥测服务。除非适用法律明确要求，开发者不会允许人工读取用户数据；由于审计数据默认只保存在用户设备上，开发者通常无法访问这些数据。

5. 权限用途

  • activeTab：用户主动使用扩展时，临时读取当前标签页以完成页面扫描和网页定位。
  • tabs：识别当前活动标签页的 URL 和导航状态，以加载对应报告并为当前网站请求权限；不用于建立浏览历史。
  • scripting：按需注入页面采集器、独立标注层，以及用户主动开始追踪测试时的临时观察器。
  • storage：在浏览器会话或扩展本地保存报告、设置、导入后的规范字段、诊断、API Key 和 AI 对话。
  • sidePanel：在 Chrome 侧边栏显示扩展界面。
  • 可选网站权限：仅在用户主动选择持续检测当前网站、运行该来源的站点审计、检查跨域语言页或移动版关联地址、继续跨域转化测试或配置 AI 服务时，申请相应 HTTP/HTTPS 地址的访问权限。海外概况不自动申请关联版本权限；用户可以拒绝或在 Chrome 扩展设置中撤销权限。

本扩展不申请 debugger 或 webRequest 权限。证书到期时间、证书链、TLS 版本与加密套件不在本扩展处理范围内；HTTPS 检查只使用浏览器已经完成的连接结果、协议、最终地址和 HSTS 响应头。

6. 数据安全

本扩展遵循最小权限和按需访问原则。传输到远程 AI 服务的用户数据要求使用 HTTPS。扩展包不加载或执行远程代码。API Key 不会写入导出的 Markdown/JSON 报告，也不会发送给开发者。

任何本地存储或网络传输都无法保证绝对安全。用户应保护其 Chrome 用户配置文件，只向可信的 AI 服务提供 API Key，并避免导入不必要的敏感信息。

7. 用户控制与数据删除

用户可以在本扩展内删除单个导入数据集、单次追踪测试、当前项目海外数据、当前项目及其站点审计和诊断数据、当前项目或全部 AI 对话、API Key，或者清除全部扩展本地数据。用户也可以在 Chrome 扩展管理页面撤销某个网站的权限。

卸载本扩展后，Chrome 会删除该扩展的本地存储。已经发送给用户所选 AI 服务的数据，需要按照该服务提供方提供的方式请求删除。

8. 儿童隐私

本扩展面向网站运营者、开发者和营销从业者，不面向儿童，也不会故意收集儿童的个人信息。

9. 政策变更

如果本扩展处理的数据类型、用途或共享方式发生实质变化，开发者会更新本政策的日期，并在适用时通过扩展界面或 Chrome Web Store 页面提供显著通知和必要的用户选择。更新后的政策不会追溯性地扩大已收集数据的用途。
