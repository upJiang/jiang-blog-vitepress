Vscode 插件开发，团队提效插件开发

> 我们经常看到一些 vscode 插件推荐的文章，可以收获到很多收藏，当一个事情需要重复做的时候，就要考虑是否能够化繁为简了。除了自己的插件开发学习之外，还会与团队迭代更新部门的 vscode 插件 lowecode

**插件的开发过程：**

- 在 `package.json` 中注册 `command`，设置 `command` 出现的位置、`title`，菜单、子菜单 等

- 在生成的插件项目中，`src` 下的 `extension.ts` 是插件的入口文件，所有的 `command`，都要在这里注册，并且命令 (`command`) 必须与`package.json` 中注册的 `command`一致。

参与的主要功能点：

- 一键生成 yapi 文档

- 一键生成文件夹文件

- 快速生成表单

- 接入 AI，生成对话聊天框，缓存聊天记录，接入大模型

- 跟 utools 插件结合

- 百度 ocr 识别表头生成代码，通用文字识别https://cloud.baidu.com/doc/OCR/s/zk3h7xz52，免费

###### 难点：

- 封装 vscode 与 webview 的通讯协议

- Webview 项目打包成一个 js，踩了不少坑

- 自动生成表单

- 插件体积优化

  - .vscodeignore 将 webview 这些无关紧要的代码忽略掉，减小打包体积，前面已经打包成一个 js，只需要打包好 js，在 vscode 根据环境引入即可

  - compression-webpack-plugin gzip 压缩

##### 关键点

- 在 AI 刚起步的时候，我们把插件接入 AI 模型对话，以及使用 typeChat（其实就是在 prompt 拼上了一个 TS 类型，要求 ChatGPT 按照 TS 类型声明输出 JSON。背后还会构建一个 TS 程序去进行校验，如果校验失败就把错误信息也加到 prompt 里，让 ChatGPT 再处理一次。） 处理数据自动 ts 格式化，自动化表单，还获得了万物云科技创新奖

- 封装 commands，命令模块化注册，提高代码复用率

- 插件支持用户自己提供 token 接入 ai，使用 requestAnimationFrame 模拟流式输出

- 自动生成表单，通过 webview 提供可视化操作需要生成的表单内容，将用户填写的内容转化成 json 传递给 vscode，然后通过 mjs 模板引擎，生成文件夹内容

  - 首先自己在 vscode 项目中定义好一些 mjs 模板，可以让 AI 根据文件内容帮你生成

  - 然后打开 webview 先让用户选择需要哪个模板，然后让用户可视化操作需要生成的表单内容，返回 json 格式对象给 vscode

  - Vscode 根据这个对象，以及选择的模板，读取 mjs 模板内容，并生成文件夹内容
