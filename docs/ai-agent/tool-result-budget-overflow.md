# Tool Result 预算、预览与外部引用

一次代码搜索可以返回几万字符，十个并行查询即使各自不过限，合计也会占满模型窗口。直接截断只留下开头，目标内容若在尾部，Agent 只能重新搜索，延迟和费用都重复发生。

**Overflow（外溢）** 先把完整 Tool Result 写入受控存储，再给模型一个有界预览和稳定引用。模型需要细节时按范围读取原对象。搬移与摘要可以组合，但外溢首先保证内容仍可恢复。

## 结果进入上下文前有四种表示

```text
raw result → stored object → bounded preview → model observation
```

原始结果带 `call_id` 和工具状态；存储对象带内容哈希、范围与生命周期；预览明确标记总大小、截取策略和是否完整；观察再加入来源与可重试性。

只保存一个临时文件路径不够。Worker 重启、Turn 跨进程恢复或容器清理后，路径可能失效。引用需要在任务生命周期内稳定，并由对象存储或持久化服务管理。

## 单结果与单 Turn 使用两套预算

单结果预算防止一个工具独占窗口，Turn 总预算限制所有工具结果的合计。并行任务在启动前预留总量，返回后按实际大小调整；不能让每条分支都以为自己拥有完整预算。

```text
preview_i <= per_result_limit
sum(preview_i) <= turn_tool_result_limit
```

超出总量时按问题覆盖、来源质量和调用优先级选择预览，不能只按完成顺序。未选中的结果仍保存引用，后续计划可以点名读取。

## 预览必须承认自己不完整

预览对象可以包含头部、尾部、命中片段和统计：

```json
{
  "call_id": "call-12",
  "complete": false,
  "raw_bytes": 84211,
  "preview": "...",
  "ref": "tool-result:run-8:call-12",
  "sha256": "..."
}
```

错误堆栈常把根因放在尾部，搜索结果需要保留命中周围，表格需要表头。统一截取前 N 字符会破坏不同数据类型的结构。预览器应按 MIME、工具类型和结果 Schema 选择策略。

## 引用要绑定权限和版本

引用不是裸 URL。读取时重新校验用户、租户、Run、工具调用和对象状态，支持按字节、行或结构化字段限制范围。引用过期返回明确错误，模型不能凭旧预览继续假设原文存在。

缓存同一对象时仍按当前权限过滤。内容哈希可用于去重和完整性校验，不能充当授权令牌。

## 写入和状态提交处理半成功

先上传对象再写 Agent 状态，状态写入失败会产生孤儿对象；先写引用再上传，模型可能读取不存在内容。常见做法是先写带短期生命周期的候选对象，状态事务提交引用后转为活动，后台清理没有活动引用的候选。

外溢器需要幂等键，同一个 `call_id` 重试不会创建多份对象。对象上传成功但回执丢失时，通过哈希和调用 ID 查询已有对象。

## 并行结果按身份融合

每个结果保留 `branch_id` 与 `call_id`，预览按计划顺序进入上下文。十条调用返回顺序随机，也不能改变证据归属和引用排序。相同内容哈希可以共享存储对象，但每个调用的状态与来源仍需保留。

分支失败时，已成功对象不必删除；融合器根据覆盖要求决定是否继续。任务取消后停止新上传，进行中的上传要完成、取消或标记孤儿，不能丢失句柄。

## 流式结果边收边限

流式工具输出需要增量计算字节与 Token 估算，达到预览上限后继续写外部对象，停止把新块追加到内存预览。总大小超过工具允许上限时主动取消下游并标记 `result_too_large`。

下游不支持取消时，继续接收并丢弃会占用带宽；直接断开又可能留下服务端任务。适配器要声明能力，运行时设置总时限与最大对象大小。

## Tool Result 成为证据还差一步

外溢只保证结果完整可找。内容能否支撑答案，还要经过权限、来源、版本、相关性和引用位置检查。工具返回成功也可能是错误数据或提示注入。

模型引用预览中的句子时，验证器应回到原对象确认位置与哈希。预览经过摘要后，摘要文本不能冒充原始引用。

## 清理不能破坏恢复

对象生命周期至少覆盖 Turn 的执行、重放和审计窗口。活动任务、未完成审批和恢复检查点引用的对象不能删除。用户删除数据或权限撤回时，对象、预览、缓存和向量派生要按来源 ID 同步清理。

后台清理只处理已确认无活动引用且超过保留期的对象，删除操作幂等并留下脱敏审计。

## 哪些结果无需外溢

短小结构化结果直接进入观察更简单；可低成本重新查询且没有审计价值的临时数据，也可以只保存参数。外溢适合大、昂贵、需要恢复或需要引用的结果。

测试需要证明完整对象哈希一致、预览明确不完整、引用越权读取失败、对象丢失产生稳定错误、并行总量不超预算、取消后无孤儿泄漏。Token 下降只是容量指标，任务仍要在需要时成功回读目标片段。
