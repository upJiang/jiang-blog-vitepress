# 07｜让权限进入每一次检索

知识库里有两份同名文档：一份所有人可见，另一份只对某个团队开放。两个用户问同一句话时，Agent 应得到不同证据；无权用户不应先检索到私密内容，再在答案末尾“过滤一下”。

本篇把权限放进检索、缓存、相邻片段和最终引用。目标是让模型从一开始就接触不到越界内容。

## 先认识 ACL 和访问范围

ACL 是访问控制列表，用来表达谁能访问某个资源。用户登录后，服务端会把身份展开为主体集合，例如用户自身、所属群组和组织。用户还可以显式选择本次只查哪几份文档，这个范围只允许继续缩小权限；扩大范围的请求应被拒绝。

```mermaid
flowchart LR
  A[登录身份] --> B[展开用户与群组主体]
  B --> C[叠加显式文档范围]
  C --> D[检索查询前过滤]
  D --> E[候选与相邻片段复核]
  E --> F[引用发布前复核]
```

## 第一步：在请求入口建立访问快照

回合创建时保存用户、知识库、群组与显式文档范围。后续每个检索分支都使用这份快照，不允许模型通过自然语言“请求扩大范围”。

管理员权限、普通用户权限和 API Token 权限要分别解析，仅看前端传来的角色字符串不足以完成授权。最终裁决来自服务端认证上下文和数据规则。

## 第二步：在数据库召回前过滤

权限条件与知识版本、片段状态一起进入查询。这样全文、向量、精确和表格通道返回的候选已经在当前用户范围内。

```text
候选可见 = 属于当前知识版本
          且片段状态可检索
          且访问主体匹配
          且位于用户显式选择范围
```

先查全库再由应用层删除，会让越界内容进入内存、重排模型、Trace 或缓存，已经造成信息暴露。

## 第三步：相邻片段也要重新校验

检索命中一个叶子片段后，系统可能补充父级或前后片段。它们虽然来自“邻居”，仍要满足同一知识版本和权限条件。否则用户可能通过一个公开片段扩展到同文档里的受限片段。

父级摘要也一样。摘要不是天然安全数据，它可能包含子节点信息。

## 第四步：缓存不能跨权限共享

缓存键包含知识版本、规范化查询和访问范围指纹。即便键已经隔离，命中后仍会重新检查当前可见性，因为权限可能刚被撤销。

这种二次检查牺牲少量性能，换来即时撤销。若业务接受短暂延迟，也可以设计更复杂的版本化权限缓存，但要明确风险窗口。

## 第五步：答案发布前再核对引用

模型生成的引用 ID 属于不可信输出。服务端检查每个引用是否来自本回合授权证据，并再次确认当前用户可见。不存在、越界或未参与本轮检索的引用不会发布。

这一步不能弥补检索前过滤，但能防止模型编造引用和权限在执行期间变化。

## 用两个用户验证

| 场景 | 用户甲 | 用户乙 | 预期 |
| --- | --- | --- | --- |
| 同名公开文档 | 可见 | 可见 | 都能检索 |
| 甲团队私密文档 | 可见 | 不可见 | 乙结果不含该片段 |
| 乙显式选择公开文档 | 不在范围 | 在范围 | 只返回选中来源 |
| 甲缓存后撤销权限 | 不可见 | 无关 | 缓存命中仍拒绝 |
| 模型伪造引用 ID | 无授权证据 | 无授权证据 | 引用校验失败 |

测试检查的不是“回答看起来没有秘密”，而是候选、相邻扩展、缓存和引用集合中都不存在越界证据。

## 当前实现的边界

本系列讨论只读知识 Agent，不提供模型发起写操作的能力。权限规则来自应用与数据库，模型只接收过滤后的结果。跨组织共享和外部来源还需各自的主体映射，不能用一个全局布尔值代替。

下一篇把已经具备权限的串行流程改造成可观察的 LangGraph 状态图。

## 用两个身份完成权限实验

建立两个匿名用户：甲只能读取“公共指南”，乙还可以读取“团队手册”。让两人查询同一句“访问权限如何申请”。检索请求必须携带由服务端展开的主体与显式资源范围，在 SQL 或等价数据查询阶段就排除不可见记录。

| 检查点 | 用户甲 | 用户乙 |
| --- | --- | --- |
| 查询前范围 | 公共指南 | 公共指南、团队手册 |
| 候选证据 | 仅公共片段 | 两类可见片段 |
| 缓存键 | 含权限版本或范围摘要 | 与甲不共享越权结果 |
| 引用发布 | 重新确认仍可见 | 重新确认仍可见 |

接着让乙查询一次并命中缓存，再撤销其团队权限。下一次查询即使缓存里还有旧候选，也要通过权限版本失效或命中后二次校验把它排除。相邻片段、父级补全和引用下载都要重复同样的资源所有权判断，不能只保护初始召回。

权限服务不可用时，安全结果是关闭受影响查询或只返回已经确定公开的范围，不是跳过过滤。把这个行为写入测试：指定范围无结果时返回“没有可见证据”，不得退回全局知识寻找一个看似有用的答案。
