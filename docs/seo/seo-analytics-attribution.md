# 怎样判断 SEO 是否真的有效

搜索平台显示 1,000 次点击，站内分析只有 860 个会话，后端收到 20 个表单，其中 6 个是有效咨询。哪个数字才是真的？它们可能都是真的，只是记录了不同阶段。

本篇建立一条从搜索展示到业务收入的数据链。重点不是追求所有平台数字完全相同，而是理解每层口径、差异和缺口。

## 先画出数据链

```mermaid
flowchart LR
  A[搜索展现] --> B[搜索点击]
  B --> C[页面到站]
  C --> D[站内行为]
  D --> E[业务提交]
  E --> F[有效结果]
  F --> G[收入和退款]
```

点击可能在页面完整加载前结束，分析脚本可能被阻止，用户也可能重复提交。后端业务记录通常更适合确认成交，搜索平台更适合分析查询和展示，两者职责不同。

## 第一步：定义核心转化

页面浏览、滚动和按钮点击是诊断行为，不一定是业务结果。核心转化应接近真实价值，例如有效咨询、完成激活、付款订单或订阅。

为事件写数据字典：事件名称、触发条件、去重规则、必要字段、隐私边界、负责人和验证方法。口径变化时记录日期，避免把新旧数据直接比较。

## 第二步：建立 URL 与查询级看板

至少按查询、页面、日期、设备、地区和品牌/非品牌拆分搜索表现，再连接页面到站、错误和业务结果。全站汇总适合观察趋势，不适合定位哪类页面出了问题。

| 层级 | 常见指标 | 主要问题 |
| --- | --- | --- |
| 搜索需求 | 查询、展现 | 用户在找什么 |
| 搜索表现 | 排名、点击、CTR | 页面是否被选择 |
| 到站体验 | 成功加载、错误、性能 | 点击是否真正到达 |
| 页面行为 | 阅读、关键步骤 | 是否理解和继续 |
| 业务系统 | 有效线索、订单、退款 | 是否产生真实价值 |

品牌查询往往转化更高，但其中很多用户已经知道品牌。与非品牌混在一起会高估 SEO 对新需求的贡献。

## 第三步：解释平台差异

搜索点击与会话不同，常见原因包括重复点击、脚本加载失败、同意选择、机器人过滤、跨域和时间区间差异。先记录口径和误差范围，不要为了让报表数字相等而重复发送事件。

归因模型也会改变“谁获得功劳”。首次接触、末次接触和数据驱动归因回答的问题不同。报告中说明采用哪种口径，并单独保留直接可核对的后端结果。

## 第四步：用实验验证修改

一次实验只测试一个主要假设，例如改写一组标题能否改善匹配查询的点击。提前选择实验页面、对照、主要指标、保护指标、观察周期和停止条件。

SEO 样本常受季节、索引延迟和结果页变化影响。样本不足时报告不确定性，不把一次短期上升包装成确定因果。

## 一个模拟对账例子

下面数字仅用于解释口径：搜索平台记录 120 次点击，站内得到 103 个会话，后端收到 8 个表单，3 个通过资格审核。正确结论不是“转化率等于某个唯一数字”，而是：

1. 点击到会话有 17 次差异，需要检查加载、同意和去重；
2. 8 个表单是提交量，3 个才是当前定义的有效咨询；
3. 若没有收入与退款数据，还不能计算最终回报。

真实项目要使用自己的数据，不用这组模拟值作为行业基准。

## 正常报告和失败报告

正常报告会写清：非品牌教程页展现上涨，到站成功稳定，有效咨询没有变化；当前假设是页面覆盖了更早期需求，下一步检查查询和后续路径。

失败报告只写“自然流量上涨 50%，SEO 成功”。它没有基线、品牌拆分、业务结果和同期变化。
