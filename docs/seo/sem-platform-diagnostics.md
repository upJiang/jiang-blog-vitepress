# Google、Bing 与百度投放诊断

一个自动化广告系列报告 ROAS 8.0，看起来应该立刻扩量。拆开后发现，大部分转化来自品牌查询、老客户和原本会自然访问的人；系统还把部分广告送到登录页。平台正确记录了归因结果，却没有证明广告创造了同等增量。

[转化与归因验收](/docs/seo/sem-creative-landing-tracking)是平台诊断的前提。主要转化、有效业务、退款、毛利和关联率尚未通过时，任何“智能扩量”结论都应暂停在数据层。

平台功能名称、入口和资格会变化。以下内容按截至 2026 年 8 月可核对的公开概念解释，实施时仍需查看账户所在地区、当前平台帮助和实际设置；诊断顺序和业务边界不依赖具体入口名称。

```mermaid
flowchart LR
  A[追踪口径] --> B[搜索词与来源]
  B --> C[成本与竞价]
  C --> D[创意与最终页面]
  D --> E[平台转化]
  E --> F[有效业务 退款 毛利]
  F --> G[预算与增量决定]
```

先验证追踪和有效业务，再讨论自动化扩量。平台报告可以作为渠道证据，但不能单独证明增量、利润或长期预算上限。

## 固定诊断顺序比平台技巧重要

无论 Google、Microsoft/Bing 还是百度，先沿同一漏斗：

```text
追踪口径 -> 搜索词与流量来源 -> 成本/竞价 -> 创意与最终页面
         -> 平台转化 -> 有效业务 -> 退款/毛利 -> 预算边界与增量
```

### 追踪与口径

确认时区、日期、归因窗口、主要/观察转化、去重、离线回传和业务关联率。追踪错误时不建议调价，因为平台和人工都在看错误目标。

### 搜索词与流量来源

检查品牌/非品牌、匹配方式、搜索词、网络/渠道、受众和新老客户。自动化报表维度不足时，应写数据缺口，不从系列总计猜流量质量。

### 成本与竞价

将 CPC、平台 CPA、有效 CPA、退款后 ROAS 和毛利回报并列。对比当前与前一等长成熟周期，排除转化延迟与重叠学习期。

### 创意与最终页面

核对用户看到的标题、描述、素材和 **Actual Final URL（实际最终网址）**。指定页面正确，不代表自动化最终一定选择它；页面 200 也不代表任务匹配。

### 有效业务与增量

平台归因不是增量。拆品牌、已有客户、地区和系列重叠，必要时用对照实验估计“没有投放会发生多少”。

## Google Search 的 AI Max

**AI Max for Search Campaigns（搜索广告系列 AI Max）**是在现有搜索系列上增加自动化能力的功能集合，可能涉及搜索词匹配扩展、文本定制和最终网址扩展，并提供相应品牌、地域或 URL 控制。具体可用项以当前账户为准。

它的输入包括关键词、广告、落地页、转化信号和账户设置；平台模型扩展查询、表达或页面选择；输出是更多搜索机会和转化。它不会理解 CRM 中未回传的“无效线索”，也不会自动知道某个页面因业务原因禁止投放。

启用前至少满足：

- 主要转化经过业务核验，重复和退款能处理；
- 品牌与非品牌有独立报告和预算边界；
- 否定词、品牌规则与敏感查询已经梳理；
- 网站合格页面清单、禁止 URL 和过期页面可控制；
- 跟踪模板在动态落地页下仍能正确展开；
- 预算有测试上限、观察期和暂停权限。

### Final URL Expansion 的风险

**Final URL Expansion（最终网址扩展）**允许系统根据查询从同一站点选择比指定页更相关的页面。它可能提高匹配，也可能绕过为特定承诺设计的落地页。

诊断必须导出或查看实际最终网址，核对页面任务、主要转化和品牌安全。登录、支付、账户、站内搜索、过期活动、测试页、低质量页和不匹配语言应排除。只看到“开启”而没有实际 URL 数据时，结论只能是待复核。

文本定制也要核对最终展示组合。价格、效果和身份不能因为由平台生成就免于广告真实性责任。

## Performance Max 不是普通搜索系列

**PMax（Performance Max，效果最大化广告系列）**以转化目标为中心，可能跨 Google 的多种广告资源和版位使用素材、商品/页面数据与受众信号。它不是“广泛匹配搜索”的另一个名称。

输入通常包括资产组、受众信号、商品或页面来源、预算、转化和价值；平台跨渠道分配展示；输出是汇总与可用明细。缺少资产组字段、渠道/搜索词可见性或实际 URL 时，应保留数据缺口。

上线前准备：

- 按产品/场景建立可审查资产组，不把所有素材混在一起；
- 上传真实、可更新的产品和价值数据；
- 设置品牌、客户获取、URL 与内容安全边界；
- 与现有品牌/搜索系列设计重叠和增量评估；
- 以有效业务和毛利作为扩量约束。

不要只看 PMax 总 ROAS。拆分品牌需求、已有客户、新客户、商品毛利、地区和实际页面；若平台维度不足，要通过业务数据和对照实验降低不确定性。

## Microsoft Advertising / Bing 怎样使用

**Microsoft Advertising** 承接 Bing 等搜索与相关广告资源。它可以使用关键词、响应式搜索广告、资产、受众、地域、时段、商品目录和自动出价，具体功能随市场与账户变化。

不要把 Google 账户原样导入后立即扩量。逐项复核：

- 时区、货币、预算和出价目标；
- 匹配行为、否定词与搜索词；
- 受众/职业等可用信号是否符合业务和合规；
- 转化代码、点击 ID、UTM 和业务回传；
- 站点链接、图片、电话、价格与最终网址；
- 搜索量、设备和地域分布是否值得单独预算。

**B2B（Business-to-Business，企业对企业）**业务可以观察职业/行业受众与高意图词组合，本地服务关注地域、营业时段和电话质量，电商核对商品源和利润。平台流量较少时，不把账户拆得过细，也不根据极小样本按小时调价。

## 百度搜索与 oCPC

**oCPC（Optimized Cost per Click，优化点击出价）**依赖转化数据预测更可能完成目标的流量，并在目标成本与量之间调整竞价。平台具体阶段、门槛和设置以当前百度营销文档/账户为准。

oCPC 的输入是账户结构、搜索词、转化事件、目标成本、预算和回传数据；处理是模型学习和出价；输出首先是平台转化与成本。若没有业务结果，无法判断系统买到的是有效客户还是廉价表单。

启用/诊断重点：

1. 中文搜索词与业务意图是否准确，品牌/通用是否分开；
2. 转化事件是否稳定、唯一、可去重，页面和回传无丢失；
3. 是否积累足够成熟样本，不频繁大改目标成本；
4. 地域、时段、预算与销售承接是否匹配；
5. 平台转化、有效转化与有效 CPA 是否连续对账；
6. 线索延迟、退款与毛利是否进入复盘。

使用 oCPC 但没有业务结果数据，应优先标 P1 数据风险，而不是建议提高预算。自动出价只能优化看得到的信号。

## 平台数据缺口本身就是诊断结果

导入或审计时常见缺口：

| 缺失字段 | 无法回答的问题 |
| --- | --- |
| 搜索词 | 匹配扩张和否定词是否合理 |
| Landing Page / Actual Final URL | 查询、创意与页面是否一致 |
| Primary/Observation | 自动策略在优化哪个目标 |
| PMax Asset Group | 哪组素材和页面承担结果 |
| AI Max / Final URL Expansion | 是否进入非预期页面 |
| 业务结果 | 平台 CPA 与有效 CPA 差多少 |
| Click ID / UTM / 归因键 | 收入能否关联到系列和词 |
| 变更记录 | 成本变化是否处于学习或多变量重叠 |

缺口不自动代表账户差，但它限制可以执行的动作。例如没有搜索词时可以修追踪和页面，不能可靠生成否定词清单。

## 品牌蚕食与 Incrementality

**Brand Cannibalization（品牌蚕食）**在这里指广告获得了本来可能通过自然品牌结果、直接访问或老客户路径发生的转化。品牌广告并非没有价值，它可以保护入口、控制信息或应对竞争，但平台 ROAS 不能自动解释增量。

**Incrementality（增量性）**实验可按相似地域、时间或受众单元设置对照，比较整体有效业务变化：

```text
增量价值 = 实验组业务变化 - 对照组同期业务变化
增量回报 = 增量价值 / 实验新增广告成本
```

实验期间保持价格、页面、转化定义和主要活动尽量稳定，记录无法控制的外部变化。样本不足时给区间与不确定性，不为证明广告有效挑选更有利窗口。

## 自动化治理清单

| 控制对象 | 允许范围 | 立即复核/停止候选 |
| --- | --- | --- |
| 转化 | 去重、业务核验的主要结果 | 页面浏览、重复表单、错误价值 |
| URL | 合格商业页和对应内容 | 登录、支付、过期、测试、空页 |
| 品牌/查询 | 明确策略并单列报告 | 用品牌掩盖非品牌获客 |
| 素材 | 真实、可验证、与页面一致 | 虚假价格、库存、效果和身份 |
| 预算 | 测试上限、成熟窗口、边际门槛 | 无回滚的大幅扩量 |
| 变更 | 单一核心变量与日志 | 多维度重叠仍宣称单项有效 |

暂停后保留配置、报表、时间线和学习状态，不立即删除证据。修复追踪或页面后再决定恢复、降级为可控策略或停止。

## 多平台诊断与止损表

```text
平台/系列类型｜日期/时区/归因｜品牌/非品牌｜搜索词可见性｜
预算/出价/变更记录｜创意/资产组｜指定与实际 URL｜
主要转化｜平台 CPA｜有效 CPA｜退款后 ROAS｜毛利回报｜
业务关联率/置信度｜自动化允许/禁止边界｜观察期｜停止/回滚
```

SEM 投手负责平台设置和报表，数据/开发负责人保证事件与业务回传，SEO/内容负责人维护允许页面与真实素材，销售确认有效线索，创业者用现金流、毛利和增量决定预算。

验收时分别为 AI Max、PMax、Microsoft/Bing 和百度 oCPC 写出启用前提、必须字段、一个数据缺口和一个停止条件。这些条件随后进入 SEO 与 SEM 的协同执行周期。
