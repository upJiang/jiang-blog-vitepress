# Google、Bing、百度 SEM 怎样诊断

某个账户的获客成本一周上涨 30%。直接降低出价、换平台还是改落地页？仅凭这个汇总数字无法判断，因为成本变化可能来自追踪、搜索词、竞争、页面、转化率或业务质量。

本篇先建立一棵三个平台都能使用的诊断树，再说明 Google、Microsoft Advertising（常被称为 Bing Ads）和百度在自动化与流量治理上的关注点。

## 先统一数据口径

诊断前记录平台、日期、时区、归因窗口、品牌规则、主要转化定义和后端业务结果。若本周把“打开表单”新增为主要转化，平台 CPA 下降并不代表业务改善。

```mermaid
flowchart LR
  A[验证追踪] --> B[检查展现]
  B --> C[检查点击相关性]
  C --> D[检查到站与转化]
  D --> E[核对业务价值]
  E --> F[再决定预算和自动化]
```

平台报表是证据的一部分，不是全部事实。有效线索、付款、退款和续费应由业务系统核对。

## 第一步：按漏斗定位异常

| 现象 | 先检查什么 | 不要立刻做什么 |
| --- | --- | --- |
| 没有展现 | 需求、状态、定位、预算、政策 | 只提高出价 |
| 有展现无点击 | 搜索词、位置、创意和品牌 | 写夸张承诺 |
| 点击多无转化 | 到站、追踪、意图、页面和表单 | 认定平台流量差 |
| 转化多价值低 | 转化定义、垃圾线索、退款 | 继续让自动化扩量 |
| 成本突然上涨 | 变更、竞争、词结构、页面、归因 | 同时改五项设置 |

一次只验证主要假设。例如先发现大量新搜索词偏离产品，再修改否定词并观察；若同时重做页面和出价，就无法确定恢复来自哪里。

## 第二步：检查账户层级和搜索词

从账户到系列、广告组、关键词、搜索词逐层拆分，找到变化集中位置。关键词是广告主设置的触发规则，搜索词是用户真正输入的内容，两者不能混为一谈。

继续按品牌与非品牌、新客与老客、地区、设备和落地页拆分。整体 CPA 上涨可能只是预算从高转化品牌词转向了新客词，这不一定是坏事；也可能是品牌流量掩盖了非品牌长期亏损。

## 第三步：自动化扩量前先建边界

平台的自动匹配、智能出价和跨资源系列会变化，但使用前提相似：主要转化可信，落地页稳定，品牌与 URL 范围清楚，预算有上限，业务价值能够回传。

允许页面可以包含经过验收的产品和方案页；登录、支付、测试、过期活动和低质量页面应排除。追踪失真、有效率持续下降或自动选择越界页面时，要有暂停或降级条件。

高 ROAS 也不自动等于高增量。自动化可能承接原本会通过品牌搜索、自然搜索或直接访问完成的订单，需要通过品牌拆分、新老用户和适当对照实验判断新增价值。

## 三个平台分别关注什么

### Google Ads

Google 的搜索自动化和跨渠道能力较多。启用更广匹配、智能出价、AI Max 或 Performance Max 之前，先查看搜索词、落地页选择、品牌边界和转化价值。Performance Max 是跨多种广告资源的系列，不能直接当成普通搜索系列比较。

### Microsoft Advertising

Microsoft Advertising 可以补充不同搜索与受众结构，也支持关键词、否定词、资产、受众和 URL 控制。从其他平台导入后，要重新检查地区、转化、匹配行为和预算，不能假设复制配置就得到相同流量。

### 百度营销

中文搜索词、账户结构、地域和落地页需要持续核对。使用 oCPC 等自动出价前，要保证有效转化稳定、能够去重，并给系统足够样本。数据质量混乱或预算过小时，自动化不会凭空创造可靠判断。

具体功能入口和名称会更新，实施时以各平台当期官方说明为准。长期不变的是：先保证数据真实，再扩大系统自由度。

## 正常诊断和失败诊断

正常记录会写：非品牌移动端 CPA 上涨；点击成本稳定，但到站成功率在某次发布后下降；追踪与后端一致；回滚页面资源后验证恢复，暂不调整出价。

失败记录只写“Google 最近流量不行，建议转投 Bing”。它没有层级、搜索词、页面、业务质量和同期变更证据。

## 怎样比较多平台预算

使用同一业务口径比较新增预算带来的新增有效价值，不只看平台平均 ROAS。平均表现好的平台可能已经接近饱和，平均较低的平台也可能带来新的用户群。

逐步调整预算，并记录保护指标：无效线索率、退款、品牌占比、页面错误和总成本。样本不足时明确写出不确定性，不要为了得出肯定结论随意放大归因窗口。

下一篇把前 17 篇内容组织成 90 天执行顺序，明确何时验证、何时扩展以及何时停止。

## 沿漏斗诊断一次成本上涨

假设账户一周内 CPA 上涨 30%。先固定日期、时区、归因和转化定义，检查同期是否修改追踪、页面、预算、出价或产品。然后按展现、点击、相关性、页面转化、业务价值逐层比较，不先归因于“竞争加剧”。

| 现象 | 优先检查 |
| --- | --- |
| 展现下降 | 需求、预算、出价、政策、地区、否定词和页面状态 |
| CTR 下降 | 真实搜索词、位置、创意承诺和品牌信任 |
| 点击正常、转化下降 | 页面可用性、速度、表单、追踪和产品匹配 |
| 平台转化正常、有效率下降 | 垃圾流量、搜索词、销售口径和价值回传 |
| 消耗上升、业务不变 | 品牌蚕食、自动化扩量和边际回报 |

Google、Microsoft/Bing 和百度的产品名称、匹配与自动化能力不同，但诊断顺序相同。不要把一个平台设置完整复制到另一个平台；先核对市场、语言、搜索量、转化导入和合规。启用自动化系列前确认主要转化可靠、品牌与否定边界清楚、页面稳定、预算有上限。

每次调整记录证据、动作、工作量、观察期、停止条件和回滚。样本不足时写“不确定”，优先可逆动作。若要判断广告是否带来新增价值，单独设计品牌拆分或地域/时间实验，不能只用平台归因总量证明增量。
