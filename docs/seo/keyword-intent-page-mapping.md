# 怎样从用户问题找到关键词

客户说“网站上线一个月了，为什么还是搜不到”，关键词工具里却只有“网站收录”“SEO 优化”这类标准词。应该按客户原话写，还是追逐工具显示的高搜索量？

关键词研究的目标不是收集尽可能多的词，而是还原用户在什么场景下、想完成什么任务。先理解需求，再决定页面和商业动作，词表才有用。

## 关键词只是需求的表达

同一个需求可以有很多说法：“网站搜不到”“网页没收录”“搜索引擎找不到页面”。文字不同，背后的任务可能相同。反过来，“Agent”这个词既可能表示概念学习，也可能是在找开发框架，不能只因词面相同就放进一页。

**搜索意图**就是用户输入查询时希望完成的任务。常见意图包括了解、操作、比较、商业调查、交易和导航。

```mermaid
flowchart LR
  A[收集用户原话] --> B[识别任务与阶段]
  B --> C[观察搜索结果]
  C --> D[合并相同意图]
  D --> E[评估价值与成本]
  E --> F[进入页面规划]
```

## 第一步：先去业务现场找问题

关键词工具适合估算和扩展，真实语义通常来自更靠近用户的地方：

- 销售咨询、客服工单和用户访谈；
- 站内搜索、没有结果的搜索和帮助中心反馈；
- 自然查询与广告搜索词；
- 产品使用障碍、购买疑虑和售后问题；
- 行业社区反复出现、现有答案又不完整的问题。

先保留用户原话，不急着翻译成术语。教程标题可以用用户语言进入，再在正文解释“索引”“幂等”等标准概念。

## 第二步：给问题标注意图

| 用户表达 | 所处阶段 | 更合适的页面 |
| --- | --- | --- |
| Agent 是什么 | 了解 | 入门教程 |
| Agent 怎样调用工具 | 操作 | 分步实践 |
| LangGraph 和 Agents SDK 区别 | 比较 | 选型指南 |
| Agent 开发服务价格 | 商业调查 | 服务或方案页 |
| 下载某个工具 | 交易 | 产品入口 |
| 某品牌登录 | 导航 | 官方入口 |

意图不能只靠“是什么”“价格”等词尾机械判断。要打开目标地区的搜索结果，观察主流结果是文章、产品、视频、工具还是官网。结果形态是当前需求的重要证据。

## 第三步：把相同任务放在一组

两个查询是否能由同一页面承载，可以问三个问题：搜索结果是否高度相似，用户最终任务是否一致，一篇页面能否自然完整回答。如果答案大多为是，就应合并，而不是一词一文。

自动聚类和向量相似度可以帮助处理大词库，但最后仍需人工检查。文字相似不等于意图相同，文字差异也不代表需要不同页面。

## 第四步：决定先做哪些需求

搜索量只是一个估算，还要结合商业价值、团队能否给出独特答案、竞争空间、可获得点击和实施成本。可以使用 1–5 分帮助排序，但每一分都要附证据。

季节性也要单独记录。一个词的月均值可能来自全年稳定需求，也可能集中在考试、节日或采购季。自然内容通常需要提前发布；广告则要为旺季竞争和预算上限做准备。

生成式摘要、地图、商品和视频可能直接满足部分查询，搜索量不等于都能获得网页点击。此时可以转向更深入的任务、工具、图片或视频结果，而不是假设所有展示都会进入网站。

## 正常词库与失败词库

正常词库至少记录原始问题、标准主题、意图、用户阶段、地区、结果类型、商业价值、目标页面和当前决策。随机抽一条，另一位成员能判断该写教程、建产品页、做广告实验还是暂不投入。

失败词库只有“关键词、搜索量、难度”三列，然后按搜索量从高到低排期。它无法判断页面类型，也会把品牌、教程、价格和售后问题混在一起。

## 竞品词需要额外边界

竞品查询可以用于研究比较需求，但内容应依据公开、可验证的差异，说明适用条件，不冒充对方，也不制造无法证明的贬低结论。广告还要遵守平台政策和商标规则。

下一篇会把已经聚类的需求变成页面清单，决定更新、合并、新建或暂缓。

## 从十条用户原话建立需求表

先收集销售、客服、站内搜索、自然查询和广告搜索词中的原句，不急着改成行业术语。以预约工具为例，“怎么避免客户爽约”“预约软件价格”“某品牌替代方案”分别接近问题解决、商业选择和比较决策，页面承诺不能完全相同。

| 字段 | 为什么要记录 |
| --- | --- |
| 原始查询 | 保留用户真实语言，避免内部术语替代需求 |
| 任务与意图 | 用户想学习、比较、购买、导航还是处理问题 |
| 结果页形态 | 当前更常出现教程、产品、视频、地图还是即时答案 |
| 商业动作 | 阅读、试用、询价、购买或线下到店 |
| 目标页面 | 更新现有页、新建、合并或暂不承接 |
| 证据来源 | 查询来自哪个平台、日期、地区和设备 |

聚类时比较“同一页面能否自然完整回答”，而不只看词面相似。两个词字面接近但一个要教程、一个要产品报价，应拆开；两个词表达不同但任务和结果页高度一致，可以由同一页承接。

随机抽十条查询，让另一位执行者仅看字段就能判断应该做文章、商业页、广告验证还是暂不投入。若判断经常分歧，说明意图或页面承诺写得不清。搜索量只是估算，优先级还要结合可获得点击、商业价值、竞争与交付能力。
