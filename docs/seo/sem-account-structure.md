# SEM 搜索广告和账户结构入门

用户搜索“团队日历软件价格”，页面上同时出现自然结果和带广告标识的结果。广告主并不是简单地“买下第一名”：平台会根据查询、关键词、定位、预算、出价、广告质量和页面等条件决定哪些广告有资格展示。

本篇先走完一次搜索广告链路，再搭建一个最小账户。重点是让预算、用户意图、广告承诺、落地页和业务结果能够对应起来。

## SEM 在这里指什么

SEM 有时被用作广义搜索营销。本系列为了便于区分，把它专门用于**付费搜索广告**：用户主动输入查询，广告主参与一次展示机会的竞争，点击通常会产生成本。

广告可以快速验证需求，但不能自动修复不相关的关键词、失效页面和错误转化。暂停预算后，付费流量通常也会减少，因此要单独计算它的增量价值。

## 一次广告从查询到业务结果

```mermaid
flowchart LR
  A[用户查询] --> B[匹配候选广告]
  B --> C[预算与政策过滤]
  C --> D[竞价与质量判断]
  D --> E[广告展示和点击]
  E --> F[落地页]
  F --> G[有效业务结果]
```

出价只影响链路中的一部分。查询是否相关、广告是否兑现需求、页面能否使用、追踪是否准确，都会改变最终结果。遇到点击多但无有效客户时，直接提高出价只会更快花钱。

## 第一步：先定义主要转化

平台可以记录按钮点击、表单提交或订单，但团队要决定哪个事件代表主要业务结果。服务网站可以记录经过后端校验的有效咨询，SaaS 可以记录激活或订阅，电商可以连接付款和退款。

页面浏览或任意按钮适合作为辅助观察，不应与主要转化混在一起交给自动出价学习。否则系统可能优化出更多便宜点击，却没有新增业务。

## 第二步：理解账户层级

不同平台名称略有差异，常见结构可以理解为：

| 层级 | 负责什么 | 什么时候需要拆分 |
| --- | --- | --- |
| 账户 | 业务主体、权限与结算 | 主体或币种确实不同 |
| 广告系列 | 目标、预算、地区和出价 | 需要独立控制预算或目标 |
| 广告组 | 一组相近搜索意图 | 需要不同广告承诺 |
| 关键词/定位 | 允许触发的需求范围 | 根据查询治理 |
| 广告与资产 | 对用户表达承诺 | 与意图和页面保持一致 |
| 落地页 | 完成任务和记录结果 | 对应唯一主要意图 |

结构太粗会把完全不同的需求混在一个预算中；结构太细又会让每组数据太少。拆分依据应是控制和分析需要，不是“一个词必须一个广告组”。

## 第三步：搭一个最小账户

假设产品是一款预约软件，可以先分为品牌、通用商业和行业方案三个系列。品牌词用于已有需求，通用词验证陌生用户，行业词使用对应页面解释特殊流程。

每个系列都记录目标、预算上限、地区、主要转化、落地页和停止条件。广告组内的查询应该能够共用一份真实承诺，例如“预约提醒”与“减少爽约”可能相关，但“软件价格”需要不同页面和表达。

品牌与非品牌要分开看。品牌搜索往往成本低、转化高，却可能主要承接已经知道你的用户；把它与陌生用户获客混在一起，会让整体数据显得过于乐观。

## 第四步：上线前做一次完整验收

1. 预算、地区、语言和时间符合真实服务范围；
2. 每组关键词、广告和落地页承诺一致；
3. 主要转化能在测试后与后端业务记录核对；
4. 登录页、过期活动和错误页面不会成为落地页；
5. 商标、价格、隐私和行业政策已经检查；
6. 有异常花费告警和能够暂停的负责人。

首周先确认系统是否按计划运行，而不是只问“是否盈利”。追踪错误、错误地区和失效页面要及时停止；样本不足时，不要因为单日 CPA 波动频繁重构账户。

## 正常结果和失败结果

正常账户能回答：这笔预算服务哪类用户、使用哪个页面、主要结果是什么、品牌和非品牌各贡献多少。

失败账户把所有产品、地区和意图放在一个系列，用“提交按钮”作为转化。即使平台显示很多转化，也无法知道哪些是有效业务，更无法控制某条业务线的预算。

下一篇继续进入关键词匹配、否定词、出价和预算，看看平台怎样决定查询是否进入竞价。

## 从业务控制需求画账户结构

搜索广告账户可以按账户、系列、广告组、关键词、创意和落地页六层理解。先列业务线、市场、预算、主要转化和落地页，再决定哪些层需要独立控制。预算或地区需要独立时拆系列；用户意图和广告承诺需要独立时拆广告组；不要为每个近义词建一个组。

| 层级 | 本层拥有的主要决策 |
| --- | --- |
| 账户 | 法律主体、币种、权限和全局追踪 |
| 系列 | 目标、预算、地区、语言和出价策略 |
| 广告组 | 紧密相关的搜索意图与承诺 |
| 关键词/受众 | 参与竞价的需求信号 |
| 创意 | 对需求的表达与差异说明 |
| 落地页 | 兑现承诺并完成主要行动 |

品牌、非品牌和竞品需求分开观察。品牌系列通常转化高，但包含已有需求，不能直接代表新增获客；竞品需求需要独立合规审查。命名中包含平台、市场、业务、目标、意图和版本，使另一位操作者可以理解，而不依赖负责人姓名。

上线前建立基线：预算上限、地域、主要转化、否定词、落地页状态和追踪对账。首周先确认流量是否按计划进入、页面是否可用、搜索词是否相关、后端是否收到有效结果。追踪失效、错误地域或页面故障应触发暂停，不通过加价掩盖结构问题。
