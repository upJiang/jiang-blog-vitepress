# 第一天投了 500 元，为什么 80 次点击没有一条有效咨询

一个创业团队把“预约软件、排班工具、免费日历、会议室预订、某竞品登录”放进同一广告组，广告统一写“专业预约管理”，全部跳首页。平台产生了展示和点击，但用户任务彼此不同：有人要购买，有人找免费工具，有人只是登录竞品。

这不是“出价太低”或“页面按钮不够醒目”，而是账户没有表达需求边界。SEM 账户结构的目标，是让预算、意图、广告承诺、落地页和转化定义保持可控。

上一篇的[查询页面分析表](/docs/seo/search-performance-attribution)与第 5 章映射表是本篇输入。已经验证的查询、页面任务、品牌分类和业务价值可以进入广告规划；没有承接页面或转化口径的词先不投。

## SEM 在本系列里指什么

**SEM（Search Engine Marketing，搜索引擎营销）**广义可包含自然和付费搜索，本系列为了便于执行，主要指搜索广告及其相关自动化投放。它解决“用户主动搜索时，创业公司怎样购买一次可控的展示机会并验证业务”。

广告上线快，不代表商业模型成熟。输入是查询需求、预算、广告素材、落地页和转化目标，平台完成匹配与竞价，输出是展示、点击、平台转化和成本；有效线索、订单、退款与毛利还要回到业务系统确认。

## 一次搜索广告如何参与竞价

**Ad Auction（广告竞价）**通常在用户发起查询时进行。平台从符合关键词、定位、政策和预算的广告中选择候选，再综合出价、广告质量、预期影响和竞争环境决定是否展示及位置。

```text
用户查询 -> 关键词/自动化匹配 -> 定位、预算与政策过滤
         -> 广告竞价 -> 创意展示 -> 点击 -> 最终落地页
         -> 平台转化 -> 有效业务 -> 收入与毛利
```

提高出价只影响其中一部分。关键词不相关、广告夸大、页面失效或追踪错误时，更高出价只会更快放大问题。

**CPC（Cost per Click，单次点击成本）**按 `广告成本 / 点击` 计算；**CTR（Click-through Rate，点击率）**按 `点击 / 展示` 计算。两者适合描述广告流量，却不证明点击有效。100 次便宜点击没有激活，可能比 20 次高价但高质量点击更差。

## 六层账户结构

不同平台名称略有差异，规划逻辑通常可以抽象为：

```text
账户 Account
└── 广告系列 Campaign：目标、预算、地区、语言、出价
    └── 广告组 Ad Group：一组可共享承诺的相近意图
        ├── 关键词 Keyword / 自动匹配边界
        ├── 否定词 Negative Keyword
        ├── 广告 Ad 与资产 Asset
        └── 落地页 Landing Page
```

### Account：业务与权限边界

**Account（账户）**通常对应一个广告主体、结算、权限和主要数据边界。法律主体、币种、市场或代理权限确实需要隔离时才建立多账户，不为重复竞争同一流量或绕过平台限制拆分。

账户层输入包括时区、货币、主要转化、品牌规则、权限和合规责任。设置后随意改时区或转化口径会破坏历史可比性。

### Campaign：预算和目标边界

**Campaign（广告系列）**承载预算、地区、语言、投放网络、出价策略和主要目标。业务线、市场、预算或转化目标需要独立控制时拆系列；只因关键词拼写不同不必拆。

品牌、非品牌核心、竞品和探索需求通常分系列，因为它们的意图、成本、增量价值和风险不同。品牌系列回报高，可能只是承接已有需求，不能掩盖非品牌获客成本。

### Ad Group：单一意图和承诺

**Ad Group（广告组）**聚合可以共享同一创意与落地页的一组相近意图。判断是否同组，问三个问题：用户任务是否一致、同一广告承诺是否准确、同一页面是否能完整兑现。

“预约软件价格”和“怎么减少客户爽约”即使属于同一产品，也应分组：前者需要价格/方案页，后者可能需要指南或行业解决方案。

结构过粗会混合意图，结构过细又会分散预算和学习样本。目标是可控制、可分析，不是广告组越多越专业。

### Keyword 与 Search Term 不同

**Keyword（广告关键词）**是广告主设置的匹配意图；**Search Term（搜索词）**是用户真实输入。一个关键词可能触发许多搜索词，平台匹配方式也会随产品变化。第 19 章将用搜索词治理实际流量。

关键词进入账户前至少有：意图、品牌分类、页面、匹配方式、业务价值和否定候选。平台推荐词不自动符合你的业务。

### Ad 与 Asset 负责表达承诺

**Ad（广告）**要回答：是不是用户所找、能得到什么、为什么可信、有哪些条件、下一步是什么。**Asset（广告资产）**是站点链接、图片、电话、位置、价格等补充信息。

价格、库存、地区和效果承诺必须能在落地页验证。多个标题资产应承担不同信息，不是把同一句话换词序。电话资产只有在团队能接听并追踪有效结果时启用。

### Landing Page 负责完成任务

**Landing Page（落地页）**是广告点击后的最终页面。SEM 页可以比 SEO 指南更聚焦单一人群和行动，但不能因此低质量或误导。

首屏应确认搜索需求、对象、价值和主要行动；随后解释方案、证据、流程、价格/限制、隐私和常见疑虑。移动端、速度、表单失败和返回路径都要验收。

不要把所有广告导向首页。若一个广告组需要多个不同页面才能兑现，通常说明意图仍混杂，或者正在做需要单独记录的落地页实验。

## 品牌、非品牌、竞品和探索怎样分层

| 意图层 | 典型任务 | 账户处理 | 主要风险 |
| --- | --- | --- | --- |
| 品牌 | 找官网、登录、价格 | 单独预算与报告 | 把已有需求当新增获客 |
| 非品牌核心 | 找产品、服务、购买方案 | 优先验证商业模型 | 竞争成本与页面承接 |
| 比较/竞品 | 比较方案和替代 | 单独创意、页面与合规 | 商标、误导和低质量比较 |
| 问题研究 | 学习和解决问题 | 控制成本，观察后续价值 | 点击多、短期转化低 |
| 探索 | 意图边界尚不明确 | 小预算、强搜索词治理 | 自动扩张和预算浪费 |

竞品广告不能冒充对方或编造负面事实，页面要清楚说明自己的身份和公开可核对差异。各平台商标政策与地区法律可能变化，上线前按当前规则审核。

## 核心转化必须在建账户前确定

**Primary Conversion（主要转化）**是希望广告系统优化的核心动作，例如有效咨询、完成试用激活或支付。浏览价格、播放视频、开始填表可作为观察转化，不应全部设为主要目标。

平台表单不是自动等于有效业务。账户规划至少记录：

```text
平台转化 -> 去重后的业务记录 -> 有效线索/订单
         -> 收入 -> 退款 -> 毛利
```

追踪尚未验收时，可以用小规模点击策略探索，但不能把错误事件交给自动出价学习。第 20 章会完整设计事件、归因和回传。

## 上线前怎样建立基线

新账户也需要基线。记录平台、日期、时区、归因窗口、品牌规则、预算、关键词、广告、落地页、主要/观察转化和业务目标。没有历史广告时，可用自然查询、销售记录和小样本实验作为低置信度输入。

首周先确认系统按计划运行：

1. 地区、语言、时段和预算没有明显错误；
2. 搜索词符合意图，否定词没有误伤；
3. 广告承诺与实际最终 URL 一致；
4. 页面、表单和移动访问可用；
5. 平台转化能与后端结果核对；
6. 品牌、非品牌和探索仍然分开；
7. 自动化没有选择登录、支付、测试或过期页面。

学习期内避免连续大改，但追踪完全失效、错误地域、失效页面、政策问题和异常消耗需要立即止损。

## 账户与意图结构图

```text
平台/账户｜市场/币种/时区｜核心业务结果｜
Campaign：目标、预算、地区、语言、出价、停止条件｜
Ad Group：用户意图、关键词边界、否定边界、广告承诺、落地页｜
主要/观察转化｜命名规则｜权限｜上线基线
```

创业者设预算、毛利和停止条件，SEM 投手设计结构与素材，SEO/内容负责人复用已验证需求和页面，开发保证落地页与追踪，数据负责人核对转化与业务结果。任何一方不能单独用平台得分决定扩量。

验收时让另一位操作者只看结构图，就能说出每个系列为什么存在、预算控制在哪里、广告组承接什么意图、用户落到哪页、怎样判断有效。下一篇会治理实际搜索词、匹配、出价和预算。
